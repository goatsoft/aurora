'@goatsoft/aurora': minor
---

Five new generators: `linear-gradient`, a plain gradient through two to four colours whose CSS fallback matches exactly; `curtain`, aurora curtains with rays rising from a bright lower edge; `treeline`, spruce silhouettes along the horizon; `rain`, falling rain that leans with the wind; and `lightning`, forked bolts and sky flashes. The starfield no longer lines its stars up in rows and diagonals. Backgrounds in one scene now recompute when any member resizes, not only on a window resize. Mountains on portrait canvases are lower in proportion, so peaks no longer turn into spikes on phones. Mountains stand still by default (`speed` 0); set it above 0 for the drifting parallax.
