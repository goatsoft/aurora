# Keyboard shortcuts

On Windows and Linux, use <kbd>Ctrl</kbd> for <kbd>⌘</kbd> and <kbd>Alt</kbd> for <kbd>⌥</kbd>. Shortcuts without a modifier don't fire while you are typing in a field.

| Keys | Action |
|---|---|
| <kbd>⌘K</kbd> | Command menu |
| <kbd>⌘Z</kbd> / <kbd>⇧⌘Z</kbd> | Undo / redo |
| <kbd>⌘S</kbd> / <kbd>⇧⌘S</kbd> | Save / save as |
| <kbd>⌘O</kbd> | Open a file |
| <kbd>⌘D</kbd> | Duplicate the layer |
| <kbd>⌫</kbd> | Delete the layer |
| <kbd>[</kbd> / <kbd>]</kbd> | Select the layer below / above |
| <kbd>⌥↑</kbd> / <kbd>⌥↓</kbd> | Move the layer up / down |
| <kbd>M</kbd> | Hide or show the layer |
| <kbd>R</kbd> | New seed for the layer |
| <kbd>Space</kbd> | Play or pause |
| <kbd>1</kbd> to <kbd>5</kbd> | Viewport size |
| <kbd>L</kbd> | Dark or light page |
| <kbd>G</kbd> | Presets |
| <kbd>F</kbd> | Focus: hide the panels |
| <kbd>Esc</kbd> | Leave focus |

In a parameter field, hold <kbd>⇧</kbd> while dragging for bigger steps and <kbd>⌥</kbd> for smaller ones. Double-click resets it.
